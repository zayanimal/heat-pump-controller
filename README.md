# Подключение UART-адаптера к ESP32-WROOM-32

## Расшифровка пинов

**ESP32 (сторона платы):**
- `IO0` (иногда подписан как "100" или "0") — GPIO0, он же BOOT
- `GND` — земля (обычно два вывода)
- `RX` — приём данных
- `TX` — передача данных
- `5V` — питание 5В (только для devkit-плат со встроенным стабилизатором!)

**UART-адаптер (FTDI / CP2102 / аналог):**
- `DTR` — Data Terminal Ready, используется для автоматического входа в режим загрузки
- `RXD` — приём данных
- `TXD` — передача данных
- `+5V` — питание 5В
- `GND` — земля
- `3V3` — питание 3.3В

## Схема подключения

| UART-адаптер | ESP32          | Комментарий                                  |
|---------------|----------------|-----------------------------------------------|
| TXD           | RX             | обязательно крест-накрест!                    |
| RXD           | TX             | обязательно крест-накрест!                    |
| GND           | GND            | любой из двух GND                             |
| 3V3           | 3.3V пин       | **не 5V**, если это голый модуль WROOM-32     |
| DTR           | IO0 (через конденсатор ~0.1мкФ) | для автозагрузки — опционально |

## Важные моменты

1. **TX/RX крест-накрест.** TX адаптера → RX платы, RXD адаптера → TX платы. Прямое соединение (TX→TX, RX→RX) работать не будет.
